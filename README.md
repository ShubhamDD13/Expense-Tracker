# 💰 Expense Tracker

A simple Expense Tracker web application built using HTML, CSS, and JavaScript. I created this project to practice JavaScript fundamentals, DOM manipulation, and event handling while building something useful.

## Features

* Add income and expense transactions
* View current balance
* Automatically calculate total income and expenses
* Delete transactions
* Responsive and clean user interface

## Built With

* HTML5
* CSS3
* JavaScript

## What I Learned

While building this project, I learned how to:

* Manipulate the DOM using JavaScript
* Handle form submissions and button events
* Store and update data dynamically
* Organize JavaScript code into reusable functions
* Improve my debugging skills
